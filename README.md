# 🌿 Plant Paradise

A modern and premium eCommerce application focused on indoor and outdoor plants.

Built using React, Redux Toolkit and Vite with a clean component architecture and responsive design.

---

## 🚀 Features

### Product Catalog

* Product listing
* Search functionality
* Category filtering
* Responsive grid layout

### Product Details

* Large product preview
* Category badges
* Ratings
* Stock availability
* Related products section

### Shopping Cart

* Add products
* Remove products
* Increase/decrease quantity
* Cart summary
* Checkout flow

### Favorites

* Add favorites
* Persistent favorites using Local Storage

### UI/UX

* Premium modern design
* Responsive layout
* Glassmorphism navbar
* Smooth hover animations
* Mobile friendly

## ⚙️ Installation

Clone repository:

```bash
git clone https://github.com/yourusername/plant-paradise-react.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build production:

```bash
npm run build
```
